## Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Raj-232/portfolio-2.0
   cd portfolio-2.0
   ```
2. **Install dependencies:**
   ```bash
   npm install
   ```
3. **Run the development server:**
   ```bash
   npm run dev
   ```
4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Customization
- Edit your details, projects, and experience in `src/app/page.tsx`.
- Update styles in `src/app/globals.css` and `tailwind.config.ts`.
